# 🧩 Screener Order Analyzer (Authenticated)

Analyze the latest **order announcements** from Screener.in  
and automatically find companies whose new orders exceed their last-year sales.

---

## ⚙️ Features

- Fetches latest 15 order-related announcements
- Extracts company, order value, and BSE link
- Pulls last-year revenue from company pages
- Compares and filters (Order ≥ Sales)
- Supports login via `sessionid` cookie
